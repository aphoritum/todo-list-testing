В ходе практической работы мы освоили работу с системой контроля версий Git 
на примере оформления тестовой документации для приложения «Список задач». 
Мы создали репозиторий, оформили 15 тест-кейсов в формате Markdown, 
объединили их в 5 тестовых пакетов, создали 2 баг-репорта и отчёт о покрытии требований.
Работа с ветками и Pull Request позволили отработать навыки командной работы. 
Все 10 требований покрыты тест-кейсами — процент покрытия составляет 100%.
Таким образом, Git является эффективным инструментом для версионирования и совместной работы над тестовой документацией.
